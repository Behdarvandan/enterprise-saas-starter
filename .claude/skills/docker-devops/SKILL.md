# Skill: Docker & DevOps Infrastructure Guidelines

## 1. Next.js 15 Docker Multi-Stage Standards

- Always use `node:20-alpine` as base image to keep image size under 150MB.
- Ensure `next.config.js` or `next.config.mjs` has `output: "standalone"`.
- Separate build stages: `deps` -> `builder` -> `runner`.
- Never run containers as `root`. Always create and use a non-root system user (`nextjs:nodejs`, UID 1001).
- Expose port `3000` and pass environment variables securely (never hardcode secrets in Dockerfile).

## 2. CI/CD & GitHub Actions Pipeline

- Pipeline stages must run in order: `lint` -> `typecheck` -> `test` -> `build-and-push`.
- Cache `node_modules` and `.next/cache` using `actions/cache` to speed up builds.
- Target deployment platform: AWS ECS Fargate or Vercel depending on environment flags.

## 3. Rule Overrides & Safety

- Dockerfiles generated by this skill MUST NOT copy `src/modules/_drafts/`.
- Ensure `.dockerignore` excludes `.git`, `node_modules`, `.next`, and `.env*.local`.
